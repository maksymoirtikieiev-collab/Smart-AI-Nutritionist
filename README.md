# 🍏 AI Nutritionist Pro (Gemini 3.1 Powered)

### 🚀 Elevator Pitch
**AI Nutritionist Pro** — це інтелектуальний веб-додаток для персоналізованого аналізу харчування. На відміну від звичайних "чат-ботів", цей проєкт реалізує концепцію **ШІ-Агента**, який використовує паттерн **Function Calling** для проведення точних математичних розрахунків за формулою Міффліна-Сан Жеора, поєднуючи гнучкість мовної моделі з надійністю програмного коду.

---

### 🎯 Цільова аудиторія
* **Люди, що ведуть ЗОЖ:** Для швидкого розрахунку КБЖВ без пошуку калькуляторів.
* **Спортсмени:** Для коригування раціону на основі точних даних.
* **Розробники ШІ-систем:** Як приклад реалізації Agentic Workflow у веб-інтерфейсі.

---

### 🧠 Технічна реалізація та ШІ-паттерни
Проєкт відповідає високим вимогам до ШІ-систем:
1. **Модель:** Використано найновішу модель **Gemini 3.1 Flash Lite**, що забезпечує мінімальну затримку (latency).
2. **Function Calling (Агентська логіка):** ШІ не "вигадує" цифри. Коли користувач надає антропометричні дані, модель автоматично викликає Python-функцію `calculate_calories()`, отримує результат і на його основі будує консультацію.
3. **UI/UX:** Професійний веб-інтерфейс на базі **Streamlit** з кастомним CSS-дизайном (м'які кути, оливкова палітра, адаптивна верстка).

---

### 🛠 Інструкція із запуску

**1. Підготовка середовища:**
Переконайтеся, що у вас встановлено Python 3.9 або вище.

**2. Встановлення залежностей:**
Виконайте команду в терміналі:
```bash
pip install streamlit google-generativeai

3. Налаштування API-ключа:

Отримайте ключ у Google AI Studio.

Відкрийте файл app.py та вставте свій ключ у змінну GEMINI_API_KEY.

4. Запуск додатка:

Bash
streamlit run app.py
Після цього додаток автоматично відкриється у вашому браузері за адресою http://localhost:8501.
